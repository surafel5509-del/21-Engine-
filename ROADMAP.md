# Godot Studio 2D - Strategic Roadmap

## Version 1.0 (Current Baseline)
- [x] Full visual 2D scene editor with grid snap and touch gestures.
- [x] Godot-inspired node hierarchy (`Node2D`, `CharacterBody2D`, `RigidBody2D`, `StaticBody2D`, `Area2D`, `CPUParticles2D`, `Camera2D`, `TileMap2D`).
- [x] Pluggable AI Copilot agent with multi-provider support (OpenAI, Gemini, Claude, DeepSeek, Ollama, Local Heuristic).
- [x] Dual scripting support (GDScript text code editor & Visual Script blocks).
- [x] 2D Physics engine with rigid bodies, box/circle colliders, triggers, friction, and bounciness.
- [x] Built-in audio synthesizer and sound effect player.
- [x] Tilemap grid editor with tile brushes.
- [x] Direct Android APK export system.
- [x] Live Engine Debug Console with performance metrics and AI error fixing.

## Version 1.1 (Upcoming)
- [ ] Multi-scene project workflow (switching between main menu, game levels, game over screens).
- [ ] Extended sprite sheet slice animator tool.
- [ ] Expanded local LLM ONNX integration for offline AI inference on device NPU.
- [ ] Custom shader graph node editor.

## Version 1.2 (Future Expansion)
- [ ] Joint and ragdoll physics (HingeJoint2D, DistanceJoint2D).
- [ ] Bluetooth keyboard and mouse shortcut mappings for tablet productivity.
- [ ] Cloud project sync and asset store sharing.
