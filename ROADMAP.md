# Apex2D Game Engine Development Roadmap

## Milestone 1: Modular Engine Core & Architecture
- [x] High-performance 2D Canvas Renderer with camera matrix support
- [x] Scene graph, GameObject, Component lifecycle
- [x] 2D Physics world with body dynamics, colliders, and triggers
- [x] CPU particle emitter system
- [x] Synthesized audio manager and PCM playback

## Milestone 2: Android Visual Studio & Touch Editor
- [x] Immersive dark Compose UI with multi-dock layout
- [x] Touch viewport pan, zoom, selection gizmos, brush tool, and snap grid
- [x] Hierarchy Scene Tree with parent-child relationships
- [x] Inspector dock for real-time node property editing
- [x] Asset Library & Procedural Asset Synthesizer

## Milestone 3: Scripting, Tilemap & Debug Console
- [x] GDScript / Lua-like Script Code Editor with syntax highlighting
- [x] Visual Scripting event-action builder
- [x] TileMap grid picker and tile painter tool
- [x] Embedded Debug Console log viewer with error diagnostics

## Milestone 4: Modular AI Agent Integration
- [x] `AiProvider` interface supporting Gemini, OpenAI, Claude, DeepSeek, Local LLMs
- [x] `AiEngineToolExecutor` with project manipulation tools
- [x] AI Assistant Dock UI with chat interface and quick action chips
- [x] Configurable AI settings modal

## Milestone 5: Project Management & APK Export
- [x] JSON / ZIP Project save, load, export, and import
- [x] APK Export bundle packager dialog
- [x] Project templates (Platformer, Physics Sandbox, Flappy, TopDown)
